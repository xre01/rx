# Current release verification

Work remains on design/sanctuary-reference-polish, PR #11; main is unchanged.

## Current behavior

The reflection editor is empty by default, without a placeholder, table, toggle or automatically inserted statistics. Existing personal drafts are restored. The original summary calculation remains in the Notion submission, with protection against duplicate statistics in drafts from intermediate previews. Attachment, link, date, history and save handlers remain available.

Study Calendar and Daily Reflection use equal-height rows. Reading statistics use CSS glass gradients and shadows; Reading search, Write note and Books share one row.

## Resource and CSS cleanup

Only app.css is loaded and precached. The ten retired secondary stylesheets remain deleted. CSS syntax and exact selector/property duplicates within the same condition/priority are tested. Responsive and interaction-state cascading is intentional and retained; this is not a claim that CSS has no cascade.

All 13 runtime stylesheet/image/icon/manifest assets, including assets/ subdirectory images, have references outside the offline precache; no byte-identical binary assets remain. Obsolete review screenshots from intermediate designs are removed. Source files used to rebuild the rich editor and operational documentation remain required.

JS/CSS URLs now use content hashes generated by scripts/version-assets.cjs. HTML, service worker imports and precache fingerprints must match current file bytes. Static cache version: rex-focus-offline-20261027-audit1. Activation removes only retired rex-focus-offline-* caches and obsolete entries in the current static cache. Other caches, localStorage and IndexedDB learning/draft records are preserved. Devices perform cleanup when the new service worker activates online; previously offline devices cannot be cleared remotely.

## Verification and limits

31 automated regression scripts cover PTE counts/targets, XP, timers, notification scheduling, offline queues, Reading notes/articles/rich text/attachments/date handling, Notion retries/conflicts, D1 reconciliation, summary draft preservation, single summary upload, resource cleanup and content versions.

Desktop browser checks verify equal calendar/reflection heights, an empty reflection editor, one stylesheet, Reading navigation, the search/actions row and no horizontal page overflow. The HTTP-only local browser preview does not expose crypto.randomUUID, so Daily Reflection initialization and opening the Reading editor cannot be interaction-verified on that test origin. HTTPS is required by the app; jsdom regression tests exercise these handlers with a secure API stub. This limitation is not counted as a successful browser interaction check.

Live Notion/D1 production authentication and writes are not verified without account credentials. Tests use isolated data and mocked endpoints; no production learning records are changed.
